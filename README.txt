# Birthday Website — For My Pretty Angel ♡

## Open it
1. Open this folder in VS Code.
2. Open `index.html`.
3. For the smoothest experience, install the VS Code **Live Server** extension and click **Go Live**.
4. Send her the hosted link (GitHub Pages / Netlify / Vercel) at 12:00 AM.

## Photos
The five supplied photos are in `images/` and are already wired into the page.

## Personalization
Edit the text in `index.html` if you want to change any line before sending it.
